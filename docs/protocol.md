# Протокол обмена: хост ⇄ плата (USB-CDC, 115200)

Текстовые строки, разделитель `\n`. Команды хоста — заглавными.
Кадр изображения передаётся одним бинарным блоком сразу после строки-заголовка.

## Хост → плата

| Команда | Ответ | Смысл |
|---|---|---|
| `PING` | `PONG` | проверка связи |
| `STAT` | `STAT ver=0.1.0 up=… imgs=… heap=… T=… RH=…` | телеметрия платы |
| `ENV?` | `ENV T=23.4 RH=41.2` | замер SHTC3 прямо сейчас |
| `IMG <len> <crc32>` + `<len>` байт | `OK IMG <ms>` | кадр 5000 Б: 1 бит/пиксель, 1 = белый, 0 = чёрный, построчно (25 Б на строку), старший бит — левый пиксель |
| `CLR` | `OK CLR` | залить экран белым |
| `TEST` | `OK IMG <ms>` | встроенная шахматка-самопроверка |

Ошибки: `ERR bad_len <n>`, `ERR short_read <got>/<len>`, `ERR crc`, `ERR unknown_cmd <cmd>`.
CRC считается как zlib.crc32 кадра; `0` в поле CRC = не проверять.

## Плата → хост (асинхронно)

| Строка | Когда |
|---|---|
| `RDY inkmetrics 0.1.0` | после старта платы |
| `EVT <BOOT\|PWR> DOWN` | кнопка нажата |
| `EVT <BOOT\|PWR> SHORT` | отпущена раньше 800 мс |
| `EVT <BOOT\|PWR> LONG` | удержание ≥ 800 мс |
| `EVT <BOOT\|PWR> HOLD` | удержание ≥ 3 с |
| `EVT <BOOT\|PWR> UP <ms>` | отпущена (с временем удержания) |
| `ENV T=23.4 RH=41.2` | при старте и каждые 30 с |
| `OK IMG <ms>` / `ERR …` | подтверждение кадра |

## Как это использует агент

- `EVT …` → действие из `config.json` (`buttons`), действия: `refresh`,
  `page_next`, `page_prev`, `test`, `clr`, `exec:<команда>`, `url:<адрес>`, `none`.
- `ENV …` → нижняя строка кадра (температура и влажность у экрана).
- Кадр отправляется по таймеру (`refresh_sec`), по кнопке или из веб-UI.

## Что планируется (Ф6)

- `PART <x> <y> <w> <h> <len> <crc>` — частичное обновление области
  (панель умеет partial refresh с другой волновой формой, ~0.3 с вместо ~2 с).
- `VOLT?` — напряжение батареи (нужно включить VBAT_PWR GPIO17 и АЦП).
