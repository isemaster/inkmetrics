# inkmetrics

Настольное табло на **ESP32-S3 с e-ink панелью 200×200**: показывает метрики компьютера —
загрузку CPU, памяти и диска, загрузку и температуру видеокарт, аптайм и наличие интернета.

Связь — **один USB-кабель**: прибор отдаётся хосту как составное USB-устройство (сетевая
карта RNDIS + флешка). Ни Wi-Fi, ни драйверов, ни интернета прибору не нужно: ПК-агент раз в
минуту собирает метрики и отправляет их на прибор по адресу `192.168.7.1` (`POST /ingest`).

*An ESP32-S3 desk panel with a 200×200 e-paper display showing a Windows PC's metrics
(CPU/RAM/disk/GPU load, GPU temperatures, uptime, internet reachability). The PC side is a
single-file PowerShell agent installed from the device's own flash drive; the link is one USB
cable, no Wi-Fi and no extra drivers.*

## Что лежит в репозитории

| Папка | Что это |
|---|---|
| `idf/` | прошивка (ESP-IDF 5.5): экран, страницы прибора, настройки, диск, USB-дескрипторы |
| `agent-kit/` | агент для ПК: `instagent.cmd` и `deinstall.cmd` (код агента внутри файлов) + инструкции RU/EN |
| `flash-kit/` | готовый комплект для заливки на другом компьютере: `idf/flash.bat`, образы, `START-HERE.txt`, копии скриптов агента |
| `tools/` | сборка и генераторы: шрифты, образ диска, комплект для переноса, стенд макета экрана, диагностика |
| `docs/` | протокол обмена, распиновка, адресация, раскладка экрана, заметки по выпуску |

В репозиторий не попадают (см. `.gitignore`): каталоги сборки, скачанные компоненты IDF,
образ диска-источник `firmware/media/*.img` (готовая копия лежит в комплекте), архивы
`flash-kit-*.zip` и рабочие заметки проекта (`MEMORY.md`, `ISSUES.md`, `NEXT-SESSION.md`).

## Сборка и заливка

```bash
# 1. прошивка (нужен ESP-IDF 5.5)
python C:/esp/idf_build.py -C idf build          # или: idf.py -C idf build

# 2. образ диска прибора: скрипты агента и инструкции в файловой системе FAT
python tools/make_setup_disk.py

# 3. комплект для другого компьютера: образы и скрипты складываются в flash-kit/
python tools/make_flash_kit.py
```

Заливка — из комплекта: `flash-kit/idf/flash.bat COMx` (подставьте свой порт). Перед записью
`.bat` сам уводит прибор в загрузчик запросом `GET /api/boot` — кнопку BOOT нажимать не надо.
В рабочем режиме прибор виден как RNDIS-сеть (`192.168.7.1`) и флешка с файлами агента.

Альтернатива из репозитория: `python tools/try_flash.py` — сам находит порт, пишет прошивку
и образ диска, проверяет страницу прибора по HTTP.

## Агент на ПК

1. Скопировать `agent-kit/` (или один файл `instagent.cmd` с флешки прибора) на компьютер.
2. Запустить `instagent.cmd` **от администратора**: агент ляжет в `C:\ProgramData\inkmetrics`,
   задача планировщика «inkmetrics agent» будет запускать его каждую минуту от SYSTEM.
3. Проверить: `C:\ProgramData\inkmetrics\agent.log` — раз в минуту строка вида
   `sent ok (cpu=8.4%, ping YA.RU 16ms 4/4)`.
4. Удаление — `deinstall.cmd` (снимает задачу, процесс и папку).

Верхняя строка прибора показывает интернет хоста: `PING - 16MS - 4/4`, при молчании ICMP, но
открытом 443 — `PING - <мс>MS - TCP`, при отсутствии ответов — `OFFLINE - 0/4`, когда агент
молчит — `NO DATA`. Узел для проверки задаётся на странице прибора `/setup` и раздаётся
агентам с прибора.
