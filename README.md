# inkmetrics

Информационный экран на Waveshare **ESP32-S3-ePaper-1.54** (200×200), подключённый
к ПК по USB. Хост-агент собирает данные (температуры железа, баланс DeepSeek,
ОЗУ/диски, локальные сервисы), рисует кадр и отправляет его на плату.
Кнопки платы настраиваются в браузере.

## Быстрый старт

```bash
# 1) запустить агент (настроить данные и кнопки в браузере)
cd D:\inkmetrics\host
C:\Python314\python.exe inkmetrics.py
#   -> веб-UI: http://127.0.0.1:8787

# без платы (только предпросмотр кадра):
C:\Python314\python.exe inkmetrics.py --mock

# один кадр в PNG:
C:\Python314\python.exe inkmetrics.py --once preview.png
```

```bash
# 2) прошить плату (сначала бэкап старой прошивки!)
cd D:\inkmetrics
bash tools/flash.sh            # бэкап в firmware/backup + запись inkmetrics
bash tools/build.sh            # только собрать
```

## Веб-доступ по USB (работает сейчас)

1. Подключи прибор — на хосте появляется съёмный диск **1,44 МБ** (например `E:`).
2. Открой файл `INKMETRICS.HTM` **в Chrome или Edge** (Firefox и Safari не умеют Web Serial).
3. Нажми «Подключить прибор» и выбери в списке COM-порт прибора.
4. Дальше страница показывает состояние прибора (прошивка, T/RH, аптайм, память),
   позволяет слать команды (`PING`, `STAT`, `TEST`, `CLR`, инверсия, перезагрузка)
   и **рисовать кадр для панели прямо в браузере** — кнопка «Показать на приборе».

На хосте при этом не устанавливается ничего: прибор сам отдаёт и диск, и страницу,
а общение идёт через Web Serial тем же портом, которым пользуется прошивка.

**Диск не только для чтения:** на прибор можно копировать файлы (конфиг, логи, свои
страницы) — они лежат в отдельном разделе флеша и переживают перезагрузку и
перепрошивку приложения. Служебные команды: `MSCINFO` (сколько занято, сколько файлов),
`MSCFMT` (переформатировать: файлы хоста стираются, страница возвращается).

Размер диска выбран как у дискеты (2880 секторов, 1,44 МБ) осознанно: том без таблицы
разделов Windows монтирует только до этого размера.

**Прошивка прибора идёт через команду `DFU`** (в OTG-режиме порт загрузчика появляется
только так): `bash tools/flash.sh` сам отправляет `DFU`, ждёт порт загрузчика и пишет
прошивку. Ручной путь, если автоматика не сработала: зажать `BOOT` и передёрнуть USB,
затем повторить `flash.sh`.


| Файл | Назначение |
|---|---|
| `firmware/inkmetrics/` | прошивка: драйвер панели, SHTC3, кнопки, протокол |
| `host/inkmetrics.py` | агент: связь, метрики, рендер, веб-UI |
| `host/web/` | веб-интерфейс настройки |
| `docs/pins.md` | распиновка (проверена по примерам Waveshare) |
| `docs/protocol.md` | протокол обмена с платой |
| `MEMORY.md` | решения, ошибки, дорожная карта |

## Веб-UI (127.0.0.1:8787)

- предпросмотр кадра (как будет выглядеть экран) и кнопки «обновить/страница/TEST/CLR»;
- таблица текущих данных (CPU, GPU, ОЗУ, DeepSeek, llama-server);
- страницы экрана: какие виджеты показывать (checkbox-список);
- привязка жестов кнопок BOOT/PWR: коротко/долго/очень долго → любое действие;
- интервал автообновления, автосмена страниц, нижняя строка;
- журнал и консоль команд плате (`PING`, `STAT`, `ENV?`, `TEST`, `CLR`).

## Ограничения, о которых стоит знать

- **Температура CPU** на Windows без драйвера недоступна. Агент покажет её,
  если запущен LibreHardwareMonitor; иначе — `n/a`. GPU-температуры есть всегда (nvidia-smi).
- Полная перерисовка e-paper ≈ 2 с, поэтому обновление по умолчанию раз в 60 с.
  Частичное обновление — в планах (Ф6).
- Плата должна быть подключена: если COM-порта нет, агент работает в режиме
  предпросмотра и пишет об этом в журнал.
